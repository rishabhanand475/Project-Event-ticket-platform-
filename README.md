# Event Ticket Platform

Spring Boot backend for an event ticket booking platform.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- OAuth2 Resource Server
- Keycloak
- MySQL
- Docker Compose

## Running the Project

1. Start MySQL and Keycloak
2. Configure database credentials
3. Run:

```bash
mvn spring-boot:run
```

## Features

- JWT Authentication with Keycloak
- Event Management
- Ticket Booking
- MySQL Persistence
- REST APIs
